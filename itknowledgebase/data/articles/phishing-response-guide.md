# Phishing and Suspicious Message Response Guide

## Recognizing suspicious messages

Phishing messages try to persuade a recipient to disclose information, approve access, open a harmful file, or visit a fraudulent site. Warning signs include unexpected urgency, unusual payment instructions, requests for passwords or MFA codes, mismatched sender addresses, unfamiliar file-sharing notices, and login pages reached through unsolicited links.

A familiar display name or an existing email thread does not prove that a message is safe. Attackers may imitate a colleague or use a compromised external account. Northstar Labs employees should verify unusual financial, identity, or access requests through a separate trusted channel.

## If you have not interacted with the message

Do not click links, open attachments, reply, forward the message normally, or call a phone number contained in it. Use the mail client's **Report Phishing** action. That action sends the original technical details to Security Operations and removes the message from the inbox.

If the reporting action is unavailable, create a Security Service Desk ticket and include the message as an attachment. A screenshot alone may omit information needed for investigation. Do not post the suspicious content in a public chat channel.

After reporting, wait for guidance before permanently deleting the message. Security Operations may search for and remove related messages from other mailboxes.

## If you clicked a link or opened an attachment

Stop interacting with the page or file. Disconnect the computer from wired, wireless, and VPN networks, but leave it powered on unless it is actively causing physical danger. From a different trusted device, call the internal security hotline. Tell the responder what was clicked or opened, when it happened, and what the computer displayed.

Do not attempt to clean the computer, delete browser history, or run an unapproved security utility. Preserving evidence helps the response team determine what occurred.

## If you entered credentials or approved MFA

Call the security hotline immediately. From a separate trusted device, change the affected company password and reject any new MFA prompts. Tell Security Operations whether a password, recovery code, payment detail, or MFA approval was provided. The team may revoke sessions, reset authentication methods, isolate devices, and review account activity.

An employee who accidentally approved an MFA prompt should not wait to see whether the account is misused. Early reporting reduces impact and is treated as responsible behavior.

## Other channels

Phishing can arrive through text messages, collaboration tools, social media, QR codes, or voice calls. Apply the same reporting principles. Never install remote-control software or share a screen because an unsolicited caller claims to represent IT. Northstar support staff do not ask users to reveal passwords or one-time MFA codes.

## Security Operations response

Security Operations acknowledges urgent reports as quickly as possible, assesses affected accounts and devices, and classifies material events using the incident severity standard. Reporters may be asked for additional context. Details should be shared only with responders who are participating in the investigation.
